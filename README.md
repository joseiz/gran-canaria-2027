# Gran Canaria · 18–22 enero 2027

Guía de viaje estática (HTML, CSS y JS sin dependencias) para la semana en Gran Canaria: tour por la isla, plan día a día y checklist. La checklist guarda su progreso en el navegador.

## Ver en local

Abrid `index.html` en el navegador, o desde la carpeta:

```bash
python3 -m http.server 8000
```

## Desplegar en Vercel

1. Subid el repo a GitHub (ya configurado).
2. En [vercel.com/new](https://vercel.com/new), importad el repositorio.
3. Framework preset: **Other**. No hace falta build command ni output directory.
4. Deploy. Cada `git push` a `main` vuelve a desplegar automáticamente.
