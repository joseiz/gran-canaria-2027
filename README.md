# Gran Canaria · enero 2027

Guía de viaje estática (HTML, CSS y JS sin dependencias) para la visita a Gran Canaria: tres días laborables por la tarde, un día de fin de semana por la zona norte y checklist. La checklist guarda su progreso en el navegador.

## Ver en local

Abran `index.html` en el navegador, o desde la carpeta:

```bash
python3 -m http.server 8000
```

## Desplegar en Vercel

1. Suban el repo a GitHub (ya configurado).
2. En [vercel.com/new](https://vercel.com/new), importen el repositorio.
3. Framework preset: **Other**. No hace falta build command ni output directory.
4. Deploy. Cada `git push` a `main` vuelve a desplegar automáticamente.
